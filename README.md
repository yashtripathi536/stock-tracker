stock tracker

About the Project

This repository contains stock tracker created to track your stock record.

Project Files

- "stock-tracker.py" – Main market tracker.
- "output.txt" – If you want to save your stock record .

Technologies Used

- Python
- File handling
- Python automation

How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in a terminal.

4. Run:
   
   "python stock-tracker.py"



Purpose

The purpose of this project is to learn about market stock and having record like profit and loss.
